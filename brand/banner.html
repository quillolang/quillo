Quillo

The web,as a language.

Routes, HTML, components and databases are the syntax. One file, one binary.

quillolang.org · github.com/quillolang/quillo
notes.qwe
db.open("app.db")

server fn total() -> int with db =
    db.query("select count(*) as n
              from notes")[0].n

component Notes() {
    state n = 0
    <button @click={() => { n = total() }}>
        {n} notes
    </button>
}

route GET / = <Notes/>
