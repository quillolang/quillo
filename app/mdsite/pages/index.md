# Field Notes

A small website made of **Markdown pages**, served by one Quillo program.

Each page is a file in `pages/`. The sidebar lists them in the order `NAV` gives in
`main.qwe`, and each page links to the one before it and the one after.

- [Getting started](/getting-started): run it and add a page.
- [Writing pages](/guide/writing): what Markdown gives you.
- [Code](/guide/code): fenced code, highlighted.

> Edit any file in `pages/` while the program runs with `--watch`: the page in the browser
> reloads by itself.
